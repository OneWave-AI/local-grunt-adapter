# Third-party software and models

The MIT license covers the code authored for this repository. Dependencies installed by the package manager retain their own licenses; inspect the lockfile and installed distribution metadata.

No model weights, model runtime binaries, private client configurations or runtime data are distributed. Ollama, llama.cpp and any selected model are separate installations. Check the exact model's license, usage terms and attribution requirements before using or redistributing it. In particular, Llama models have their own license and attribution terms; they are not relicensed under this repository's MIT license.
