# Contributing

Open an issue describing a reproducible problem, or submit a focused pull request with relevant tests. Use synthetic input in examples, tests and reports. Never attach private task data, local state, tokens or client configuration backups.

Run the checks in the README before submitting a change. Keep local-only networking and private-output handling intact. Treat generated answers as drafts; passing a schema does not establish factual correctness.

Contributions are provided under the repository's MIT license. Model weights and third-party dependencies retain their own licenses.
